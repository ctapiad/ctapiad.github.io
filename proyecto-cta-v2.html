Resumen del Proyecto

Evolución

Segunda generación del sistema de gestión del CTA. Reemplaza el stack basado en Microsoft Forms y Power Pages por una aplicación web React moderna desplegada en Vercel.

Rendimiento

Tiempos de respuesta reducidos de más de 5 minutos a menos de 8 segundos gracias al procesamiento paralelo de consultas y filtrado en el navegador.

Cobertura

Gestiona equipos audiovisuales (cámaras, micrófonos, grabadoras) y tres tipos de recintos (Sonido, Audiovisual, Animación) con reserva, disponibilidad y seguimiento.

Contexto y Motivación

¿Por qué una v2?

El sistema original fue construido sobre el ecosistema de Microsoft 365 (Power Automate + Microsoft Forms + SharePoint + Power Pages). Si bien fue funcional y ganó el Premio de Innovación DuocUC 2024, presentaba limitaciones importantes:

Interfaz limitada por Power Pages

La personalización visual y la experiencia de usuario estaban restringidas por las capacidades de Power Pages, con tiempos de carga elevados.

Sin disponibilidad en tiempo real

El sistema original no podía verificar la disponibilidad de equipos antes de enviar la solicitud, lo que generaba conflictos de reserva.

Formularios separados por módulo

Cada tipo de reserva (equipos, estudio de sonido, sala audiovisual) tenía un formulario independiente, fragmentando la experiencia del usuario.

Escalabilidad reducida

Agregar nuevas funcionalidades requería modificar múltiples flows de Power Automate sin posibilidad de control de versiones adecuado.

Decisión Técnica

Se decidió migrar el frontend a React 19 desplegado en Vercel, manteniendo Power Automate y SharePoint como backend de datos. Esta arquitectura desacoplada permite evolucionar el frontend de forma independiente, aplicar control de versiones con Git y lograr una experiencia de usuario de nivel profesional.

La Solución

Una Single Page Application (SPA) desarrollada en React y Vite, conectada a 8 flows de Power Automate que actúan como API REST, con SharePoint Lists como base de datos persistente y desplegada en producción mediante Vercel con CI/CD automático.

Arquitectura del Sistema

React 19 + Vite

Aplicación SPA con React Router DOM para navegación client-side. Build tooling con Vite + Rolldown para compilaciones ultrarrápidas.

8 Flows Power Automate

Cada flow actúa como endpoint HTTP: obtener recursos, crear solicitudes de equipos y recintos, validar correos institucionales, consultar disponibilidad y listar historial.

SharePoint Lists

Listas Solicitud de Equipos y Reserva de Espacios CTA como base de datos. Columna RecursosJSON para almacenar reservas de kits estructuradas en JSON.

Validación Institucional

Flow dedicado verifica en tiempo real que el correo del alumno exista en el directorio de DuocUC (@duoc.cl / @duocuc.cl) antes de permitir cualquier solicitud.

Calendario de Disponibilidad

Cada equipo/kit muestra un calendario visual con estados (Pendiente, Agendado, Entregado) consultados directamente desde SharePoint via Power Automate.

CI/CD con Vercel

Cada push a la rama main en GitHub dispara un deploy automático. Variables de entorno con las URLs de los flows gestionadas en Vercel Dashboard.

Integración con Power Automate — 8 Flows

# Flow Función
1 Obtener Recursos Consulta catálogo completo de equipos + reservas activas desde SharePoint en paralelo
2 Crear Solicitud Registra reservas de equipos/kits en lista SharePoint con estado "Pendiente"
3 Mis Solicitudes Retorna historial de reservas de equipos filtrado por correo del alumno
4 Validar Correo Verifica existencia del correo en directorio DuocUC antes de aceptar solicitudes
5 Solicitudes por Recurso Reservas de un equipo específico para renderizar su calendario de disponibilidad
6 Crear Solicitud Recinto Registra reservas de recintos en lista Reserva de Espacios CTA
7 Disponibilidad Recinto Consulta conflictos de horario para un recinto en una fecha, retorna { disponible, conflictos }
8 Mis Solicitudes Recintos Retorna historial de reservas de recintos por correo (carga paralela con equipo)

Módulos de la Aplicación

Reserva de Equipos

Catálogo completo de equipos audiovisuales y kits. Filtrado por carrera, asignatura y docente. Sistema de carrito con selección múltiple y pre-reserva instantánea.

  • 5 carreras · 31 docentes · 41 asignaturas
  • Kits como unidades atómicas de reserva
  • Verificación dual: campo Kit + EquiposAudiovisual
  • Horarios dinámicos: Lun–Vie 08:00–22:30 · Sáb 08:00–13:30

Reserva de Recintos

Tres tipos de recintos reservables con formulario dedicado y verificación de disponibilidad en tiempo real antes de confirmar la solicitud.

  • Studios de Sonido
  • Sala Mac Studio Audiovisual
  • Lab PCs de Animación Digital
  • Mini-calendario por recinto con conflictos marcados

Mis Solicitudes (Historial)

Panel unificado de seguimiento con tabs separados para Equipos y Recintos, estadísticas de estado y carga paralela con Promise.allSettled.

  • Estados: Pendiente · Agendado · Entregado · Devuelto · Nulo
  • Filtrado por estado y rango de fechas
  • Extras normalizados (JSON array / CSV)

Flujo de Reserva de Equipos

1

Seleccionar Carrera

El alumno elige su carrera para filtrar automáticamente docentes y asignaturas disponibles.

2

Definir Fechas

Selecciona fecha y hora de retiro y devolución. Los selects muestran solo las horas habilitadas según el día de la semana.

3

Explorar Catálogo

Navega por equipos individuales y kits completos. Consulta el calendario de disponibilidad de cada ítem antes de agregar al carrito.

4

Confirmar Solicitud

Validation del correo institucional, verificación de disponibilidad pre-envío y registro en SharePoint. El equipo queda bloqueado con estado "Pendiente".

5

Seguimiento

El alumno consulta el estado de su solicitud en "Mis Solicitudes" ingresando su correo institucional en cualquier momento.
