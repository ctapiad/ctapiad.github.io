Sistema de Reservas CTA — Microservicios v2.0

v3 · Migración a arquitectura profesional con estándares empresariales

2025 – 2026 DuocUC · CTA FullStack-3

Resumen del Proyecto

Motivación

Gracias al MVP React, se identificaron limitaciones de escalar sobre Power Automate y SharePoint. Este proyecto migra el sistema a una arquitectura de microservicios desacoplada con estándares profesionales.

Arquitectura

Microservicios con BFF (Backend For Frontend), API Gateway, autenticación JWT con RBAC, PostgreSQL, RabbitMQ para eventos asíncronos y SSE para notificaciones en tiempo real.

Organización

Desarrollo activo en la organización FullStack-3 de GitHub, como proyecto del curso Desarrollo FullStack III de DuocUC.

Servicios y Componentes

cta-bff

Backend For Frontend y API Gateway. Punto único de entrada externo con verificación JWT, control de roles (alumno, docente, admin, staff) y proxy hacia microservicios internos.

cta-auth-service

Autenticación con JWT, refresh tokens, login/logout y gestión de usuarios administrativos.

cta-bookings-service

API REST principal: recursos, reservas, panel docente, notificaciones SSE y publicación de eventos a RabbitMQ.

cta-notifications-lambda

Consumidor de eventos RabbitMQ que procesa notificaciones de forma asíncrona (simula AWS Lambda).

cta-frontend + cta-admin-frontend

Dos frontends React + Vite: portal de estudiantes y panel administrativo/docente, con librería compartida cta-ui-lib.

cta-database

Esquema PostgreSQL con migraciones versionadas para recursos, reservas, usuarios y notificaciones.

Flujo de Datos

Fase Síncrona

Usuario → Frontend → BFF → bookings-service → PostgreSQL → respuesta inmediata

Fase Asíncrona

bookings-service → RabbitMQ (booking.events) → notifications-worker → log / Slack / email

Patrones de Arquitectura

BFF Pattern

Adaptación de respuestas para frontend de alumnos vs panel admin desde un único gateway.

API Gateway

Centraliza auth, RBAC y rate limiting. Microservicios internos no expuestos al exterior.

Event-Driven (EDA)

Desacopla reservas de notificaciones vía RabbitMQ Pub/Sub.

SSE en Tiempo Real

Server-Sent Events para notificaciones instantáneas a estudiantes y administradores.

Seguridad OWASP

Helmet, CORS restrictivo, rate limiting, queries parametrizadas, JWT y variables de entorno.

Docker Compose

Orquestación completa de todos los servicios para desarrollo y despliegue local.
