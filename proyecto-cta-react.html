Sistema de Reservas CTA — Versión React

v2 · Evolución del prototipo Microsoft 365 hacia una aplicación web moderna

2025 – 2026 DuocUC · CTA recursos-cta.vercel.app

Resumen del Proyecto

Origen

Evolución directa del prototipo con Microsoft 365, que validó el flujo de reservas del CTA. Este MVP React mantiene la integración con Power Automate y SharePoint como backend de datos.

Estado actual

Sigue siendo un prototipo MVP funcional desplegado en Vercel y usado activamente por estudiantes del CTA para reservar equipos y recintos audiovisuales.

Próximo paso

La experiencia y aprendizajes de este MVP impulsaron el desarrollo de la versión con microservicios, con arquitectura profesional y estándares empresariales.

Funcionalidades Principales

Reserva de Equipos

Carrito de equipos con validación de disponibilidad en tiempo real, filtros por carrera y asignatura, y restricciones horarias configurables.

Reserva de Recintos

Estudios de sonido, set de TV, sala cyber café y recintos por carrera (Audiovisual, Animación, Sonido) con verificación anti-duplicados.

Mis Solicitudes

Seguimiento del estado de reservas con historial completo y notificaciones del flujo de aprobación docente + CTA.

Validaciones de Negocio

Bloqueo global de equipos entre carreras, protección contra race conditions, restricciones de horario por equipo y validación de correos institucionales.

Stack Tecnológico

React + Vite

Frontend SPA con componentes modulares, routing y estado reactivo.

Power Automate

Flujos HTTP para crear solicitudes, verificar disponibilidad y gestionar aprobaciones.

SharePoint Lists

Base de datos de equipos, recintos, solicitudes y estados de reserva.

Vercel

Despliegue en producción con optimización de assets y CDN global.
