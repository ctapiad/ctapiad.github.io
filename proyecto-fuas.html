Entrenador FUAS

App educativa para reforzar el proceso FUAS con alumnos de cuarto medio en Chile

2025 – 2026 Duoc UC Liderazgo de desarrollo MVP

Resumen del Proyecto

Propósito

Aplicación móvil educativa para reforzar el proceso de postulación al FUAS (Fondo de Crédito Universitario) con modalidad de práctica individual y torneos guiados por reclutadores.

Estado

Proyecto en etapa temprana con MVP funcional desplegado. Estuve a cargo del desarrollo del MVP y actualmente está en proceso de innovación por la institución Duoc UC.

Nota

Proyecto educativo demostrativo. No reemplaza el proceso oficial del MINEDUC. Portal oficial: fuas.mineduc.cl

Funcionalidades

Modo Alumno

Práctica individual con banco de 54 preguntas, inicio con Google Sign-In o modo invitado, y participación en torneos con código.

Torneos en Vivo

Sala de espera con polling del estado real del torneo. El reclutador controla inicio y cierre. Pool de preguntas determinista por código de torneo.

Panel Reclutador

Dashboard con monitoreo en curso, métricas de participantes, ranking corregido, desglose por pregunta y historial de torneos completados.

Métricas y Ranking

Puntaje normalizado consistente (correctas/10), estado de participantes en tiempo real y resultados recuperables tras cerrar la app.

Arquitectura AWS

Android App

Kotlin 1.9, Jetpack Compose, Navigation Compose, Retrofit + OkHttp, Coroutines y Credential Manager (Google Sign-In).

Spring Boot

API REST desplegada en EC2 con Spring Web, Spring Data JPA, Lombok y Swagger/OpenAPI para documentación.

Amazon RDS (MySQL)

Persistencia real de usuarios, torneos, respuestas y resultados con JPA/Hibernate.

AWS EC2

Backend desplegado en instancia EC2 con API documentada vía Swagger UI.

Flujo de datos

Android App → HTTP (Retrofit) → Backend Spring Boot en EC2 → JPA/Hibernate → MySQL en Amazon RDS

Logros del MVP

App funcional

APK debug compilable con flujo completo alumno + reclutador conectado a backend real.

Backend desplegado

API REST operativa en AWS con persistencia MySQL RDS y documentación Swagger.

Torneos reales

Sistema de torneos sin datos simulados: códigos validados, control por reclutador y métricas corregidas.
